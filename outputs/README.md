# outputs/

Aqui ficam os resultados finais gerados pela análise: gráficos, tabelas e o ranking de desigualdade entre as 8 áreas do G2.

## O que vai aparecer aqui
- Gráficos comparando grupos (renda, raça, escolaridade, região) por área — formato `.png` ou `.svg`
- Tabela final com os resultados do teste qui-quadrado (p-valor por área × grupo)
- Ranking final das 8 áreas, do maior gap ao menor
